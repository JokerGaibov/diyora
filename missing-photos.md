# Блюда без реального фото

Сейчас у этих позиций стоит старое AI-фото (заглушка). Когда будет настоящее фото — положите его в `public/images/menu/` (любое новое имя, например `<id>.webp`) и впишите путь в поле `image` в `src/data/menu.ts`, либо удалите поле `image` у позиции в `src/data/menu.ts`, чтобы показывалась текстовая карточка.

| id | Блюдо | Категория |
|---|---|---|
| syltama | Сылтама с гарниром | Вторые блюда |

Самса из слоёного теста с курицей использует файл «Самса из слаённое тесто.jpg» (он совпадает с фото самсы с бараниной).

Фото с водяными знаками, которые нужно заменить: картофель фри (edimdoma), свежий овощной салат (RussianFood).
